# TEE Reference Standard V1

Reproducible methods and analysis code supporting the development of an auditable reference standard for clinical information extraction from intraoperative transesophageal echocardiography (TEE) reports.

Developed as part of the TEECompass research initiative at the University of Pennsylvania.

**Status:** Analysis code is being prepared for public release.

**Licensing:** Under institutional review. The intended license is PolyForm Noncommercial 1.0.0, permitting noncommercial research use while reserving commercial use for separate authorization.

Patient-level clinical reports and adjudication data will not be publicly released because of institutional data-sharing restrictions.

**Manuscript:** *Building an auditable reference standard for clinical information extraction: a two-institution study of intraoperative transesophageal echocardiography reports.*
