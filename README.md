# TEE Reference Standard V1

Reproducible methods and analysis code supporting the development of an auditable reference standard for clinical information extraction from intraoperative transesophageal echocardiography (TEE) reports.

Developed as part of the TEECompass research initiative, with investigators from the University of Pennsylvania and University of Washington.

## Status

Analysis code is being prepared for public release. The scope, timing, and licensing terms of any release are subject to institutional review.

## Licensing

No software license has been selected. Our goal is to facilitate broad scientific reproducibility and research use while ensuring appropriate institutional review of intellectual property and licensing considerations.

## Data Availability

Patient-level clinical reports and adjudication data are not publicly available due to institutional data-use agreements and privacy protections.
